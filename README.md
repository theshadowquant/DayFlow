# 🚀 DayFlow — Human Resource Management System

> A modern, intuitive, and scalable Human Resource Management System designed to simplify employee management, attendance, leave tracking, payroll, and HR operations.

🌐 **Live Demo:** https://day-flow-neon.vercel.app/

💻 **Source Code:** [GitHub Repository](https://github.com/theshadowquant/DayFlow)

---

## 📌 Overview

**DayFlow** is a modern Human Resource Management System built to streamline everyday HR operations through a clean and intuitive digital platform.

The application provides a centralized workspace where organizations can manage employees, monitor attendance, handle leave requests, and organize essential HR information efficiently.

The project focuses on creating a **professional, responsive, and user-friendly HR experience** while maintaining a scalable frontend architecture.

---

## ✨ Features

### 👥 Employee Management

* Add and manage employee information
* View employee profiles
* Organize employee records
* Track employee details from a centralized dashboard

### 🕐 Attendance Management

* Track employee attendance
* Monitor working hours
* View attendance history
* Quickly identify attendance status

### 🌴 Leave Management

* Submit leave requests
* Review and manage leave applications
* Track leave status
* Maintain leave records

### 📊 HR Dashboard

* Overview of important HR metrics
* Employee statistics
* Attendance insights
* Leave summaries
* Quick access to important HR operations

### 🔐 Authentication

* Secure user authentication
* Role-based access support
* Protected application routes

### 📱 Responsive Design

* Fully responsive interface
* Optimized for desktop, tablet, and mobile
* Modern navigation and reusable UI components

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/theshadowquant/DayFlow.git
```

### 2. Navigate to the project

```bash
cd DayFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Replace the values with your Supabase project credentials.

### 5. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

## ⚡ Development

This project uses **Vite** for fast development and Hot Module Replacement (HMR).

Two React plugin options are supported by the Vite ecosystem:

* `@vitejs/plugin-react`
* `@vitejs/plugin-react-swc`

DayFlow currently uses the React + Vite development setup with Oxlint for code quality.

### React Compiler

The React Compiler is currently not enabled because of its potential impact on development and build performance.

If required, it can be enabled following the official React Compiler documentation.

### Oxlint

For production applications, type-aware linting can be enabled using `oxlint-tsgolint`.

---

## 🧪 Available Scripts

```bash
# Start development server
npm run dev

# Build production version
npm run build

# Preview production build
npm run preview

# Run linting
npm run lint
```

## 🔒 Environment Variables

For security, sensitive credentials should **never be committed to GitHub**.

Make sure `.env` is included in `.gitignore`:

```text
.env
.env.local
.env.production
```

Only expose client-side environment variables that are intended to be public.
